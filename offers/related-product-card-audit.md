# Related Product Card Audit

When a related-product card links to one item but describes another, which field should your team check? This offline Python tool compares the model number in each card heading with its teaser, the parent page's model number, and your authorized item master. It returns the rows that need a catalog editor's attention.

For example, suppose the **BX-40** product page displays a card for **CX-40**. Your master contains CX-40, but the teaser mentions only BX-40. The report flags that card as `parent_only` and records its location so an editor can check which item supplied the description. Both identifiers in this example are fictional.
